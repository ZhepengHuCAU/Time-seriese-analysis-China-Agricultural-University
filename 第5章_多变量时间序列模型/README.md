# 第5章：多变量时间序列模型

本文件夹用于存放第五章相关材料。

## 主要文件

- `第5章_多变量时间序列模型_教材式中文讲义.md`：第五章主讲义，内容包括 VAR、SVAR、脉冲响应、方差分解、结构识别和 local projection。
- `脚本/VAR_SVAR_LocalProjection示例.R`：使用 `vars` 与 `lpirfs` 包演示 VAR、SVAR 和 local projection 的课堂代码。

## 文件夹结构

- `图片/`：存放第五章讲义、网页和课件中使用的图形。
- `脚本/`：存放用于生成图形、模拟数据或实证示例的代码。
- `草稿/`：存放临时数据、草稿材料或尚未整理进正式讲义的内容。

本章实证代码原则上优先使用成熟 R package，例如 `vars`、`svars`、`lpirfs` 等。除非为了讲解模型原理，一般不手写已有 package 可以可靠完成的估计和检验程序。
