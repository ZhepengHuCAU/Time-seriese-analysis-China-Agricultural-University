# 课程网站说明

## 用途

本文件夹用于生成 GitHub Pages 课程网站。

## 当前结构

- `mkdocs.yml`：网站配置文件。
- `requirements.txt`：固定本地已验证的 MkDocs、主题和公式处理版本，线上构建使用同一组版本。
- `docs/`：网站正文内容。
- `docs/index.md`：课程首页。
- `docs/第0章_绪论/index.md`：课程绪论网页内容。
- `docs/第1章_时间序列数据/index.md`：第 1 章“时间序列数据”网页内容。
- `docs/第1章_差分方程/index.md`：保留原路径，当前作为第 2 章“差分方程”网页内容。
- `docs/第2章_平稳时间序列模型/index.md`：原第 2 章，当前作为第 3 章网页内容。
- `docs/第3章_ARCH与GARCH模型/index.md`：原第 3 章，当前作为第 4 章网页内容。
- `docs/第4章_非平稳时间序列模型/index.md`：原第 4 章，当前作为第 5 章网页内容。
- `docs/第5章_多变量时间序列模型/index.md`：原第 5 章，当前作为第 6 章网页内容。
- `docs/第6章_协整与误差修正模型/index.md`：原第 6 章，当前作为第 7 章网页内容。
- `docs/第8章_政策影响评估/index.md`：第 8 章“政策影响评估”，重点介绍 RPS，提供配套 R 脚本下载。

## 发布方式

GitHub Actions 会在推送到 GitHub 后按 `requirements.txt` 安装构建依赖，严格检查网站，再发布到 GitHub Pages。线上与本地使用同一份 `mkdocs.yml`、课堂阅读样式和 MathJax 配置；不要另建一套线上字号或章节顺序。

本地重新准备环境时，在本文件夹运行 `python -m pip install -r requirements.txt`，然后运行 `python -m mkdocs serve`。浏览器缩放和窗口宽度仍会影响响应式布局；比较线上、本地排版时应使用相同缩放比例和窗口宽度。
