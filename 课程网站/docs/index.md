# 经济时间序列

本网站用于整理“中国农业大学经济时间序列”课程讲义。

课程面向应用经济系硕士生与低年级博士生，涵盖时间序列的基本性质、动态建模、统计推断和预测方法。

## 课程信息

- 任课教师：胡哲鹏
- 所属单位：中国农业大学经济管理学院

## 当前内容

- 第 1 章：时间序列数据
- 第 2 章：差分方程
- 第 3 章：平稳时间序列模型
- 第 4 章：ARCH 与 GARCH 模型
- 第 5 章：非平稳时间序列模型
- 第 6 章：多变量时间序列模型
- 第 7 章：协整与误差修正模型

- [Lab 1：结构变化、ARMA 与 ARCH/GARCH](lab-1/index.md) — 下载 Brent 数据与带有注释的 R 代码。
